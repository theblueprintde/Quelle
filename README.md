# Quelle

Payas'ın kişisel günlük plan uygulaması (Android tablet).

## Tablete kurulum

1. Tabletten bu deponun **Releases** sayfasındaki en yeni sürümü aç.
2. `Quelle.apk` dosyasını indir ve aç.
3. İlk seferde Android "bilinmeyen kaynaklardan yüklemeye izin ver" diye sorarsa izin ver.

Her güncellemede yeni APK'yı indirip kurman yeterli, verilerin silinmez.
